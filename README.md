# Estudos de Python — Desafios e Exercícios

Repositório com meus estudos de Python, do básico ao intermediário, com foco em lógica de programação e preparação para a área de dados.

## Objetivo

Consolidar a base de Python por meio de desafios práticos, cobrindo desde lógica de programação até funções, dicionários, listas e classes.

## O que tem aqui

| Categoria | O que tem |
|---|---|
| **Lógica** | Condicional, loop, operador lógico |
| **Listas** | Manipulação, busca, ordenação |
| **Dicionários** | Criação, iteração, contagem |
| **Funções** | Parâmetro, retorno, validação |
| **Strings** | Fatiamento, contagem, manipulação |
| **Loops** | `for`, `while`, `break`, `continue` |
| **Classe** | `__init__`, método, atributo |
| **Arquivo** | Ler, escrever, tratar |
